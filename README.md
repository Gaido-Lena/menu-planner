# Меню на две недели

Планировщик семейного меню: база блюд, план на 2 недели, меню для семейного чата, список покупок и план заготовок.

## Как устроено

- `index.html` — всё приложение в одном файле, без сборки. Открывается через GitHub Pages.
- Данные лежат в Supabase (проект `menu-planner`), таблица `public.planner_docs`: три строки — `dishes` (блюда), `plan` (план), `checks` (отметки в списках).
- Вход по почте и паролю (Supabase Auth). Данные видят и меняют только почты из таблицы `private.allowed_emails`.
- `supabase/migrations/` — схема базы.

## Добавить человека

1. Человек регистрируется на странице и подтверждает почту по ссылке из письма.
2. В Supabase → SQL Editor выполнить:

```sql
insert into private.allowed_emails(email) values ('name@example.com');
```

## Ключ в коде

В `index.html` записан публикуемый ключ Supabase (`sb_publishable_…`). Он рассчитан на то, чтобы быть в открытом коде: без входа и без почты из списка он не даёт доступа к данным.
